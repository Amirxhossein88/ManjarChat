# 🪙 منجرچت — ManjarChat

مسنجر مستقل و مدرن به سبک تلگرام با اقتصاد اختصاصی **«منجر»** (جایگزین استار) — ساخته‌شده با Next.js 16، TypeScript، Prisma و SQLite.

> ⚠️ این پروژه یک پیام‌رسان مستقل و الهام‌گرفته از تلگرام است؛ ارتباطی با شرکت Telegram و سرویس‌های آن (استار، پرمیوم واقعی و…) ندارد.

## ✨ امکانات

| بخش | امکانات |
|---|---|
| 💬 چت | پیام متنی، ویرایش، پاسخ (Reply)، حذف، سنجاق (Pin)، تایپینگ زنده، وضعیت آنلاین، شمارنده پیام خوانده‌نشده |
| 👥 گروه و 📣 کانال | ساخت گروه و کانال، دعوت اعضا، فقط‌مدیری در کانال، گروه عمومی خودکار برای همه کاربران |
| 🎙 پیام صوتی | ضبط با یک کلیک (MediaRecorder)، پخش‌کننده موج‌دار، مدت‌زمان خودکار |
| 🖼 رسانه | ارسال عکس با پیش‌نمایش، ارسال فایل با لینک دانلود (تا ۲۵ مگابایت) |
| 🪙 اقتصاد منجر | کیف پول، گردش حساب، چک‌این روزانه (+۲۵)، هدیه خوش‌آمدگویی (+۱۰۰) |
| 🛒 فروشگاه | پرمیوم (۳۰/۹۰ روز)، ۶ نوع هدیه با پیام ویژه، بوست گروه/کانال، رنگ‌های ویژه آواتار |
| 👑 پنل ادمین | آمار زنده، مدیریت کاربران (مسدودسازی، ادمین‌کردن)، شارژ/کسر منجر، مدیریت فروشگاه، اعلان همگانی، ورود به هر گفتگو |
| 🌙 ظاهر | تم تاریک/روشن، رابط کامل فارسی RTL، فونت وزیرمتن |

## 🐳 استقرار روی هاست (Docker)

```bash
docker compose up -d --build
```

- اپ روی پورت `3000` بالا می‌آید؛ دیتابیس و فایل‌های آپلودی رویvolume های `./db` و `./data` می‌مانند.
- برای **فعال شدن ضبط ویس** در مرورگر، سایت باید HTTPS باشد؛ یک reverse proxy با SSL (مثلاً Caddy یا Nginx + Certbot) جلوی آن بگذارید.
- اگر ادمین قبلاً ساخته شده، تغییر `ADMIN_PASSWORD` در compose پسورد فعلی را عوض نمی‌کند (فقط در اولین اجرا اعمال می‌شود).

### بدون Docker (سرور لینوکسی)

```bash
bun install
bunx prisma generate && bun run build
DATABASE_URL=file:$(pwd)/db/custom.db NODE_ENV=production PORT=3000 node .next/standalone/server.js
```

## 🖥 نسخه ویندوز (exe)

ورک‌فلو `.github/workflows/build-exe.yml` به‌صورت خودکار:

1. پروژه Next را به‌صورت standalone بیلد می‌کند،
2. یک **سرور داخلی** را داخل اپ دسکتاپ Electron جاسازی می‌کند،
3. خروجی `ManjarChat Setup x64.exe` (نصابی) و `ManjarChat-Portable-x64.exe` (پرتابل) می‌سازد،
4. روی تگ‌های `v*` فایل‌ها را در **GitHub Releases** منتشر می‌کند.

اجرای دستی: تب **Actions → Build Windows EXE → Run workflow**.

- اپ دسکتاپ به‌صورت پیش‌فرض **سرور را داخل خودش اجرا می‌کند** (بدون نیاز به هاست) و دیتا را در `AppData` نگه می‌دارد.
- از منوی برنامه می‌توانید به‌جای سرور داخلی، به **سرور هاست خودتان** وصل شوید (حالت کلاینت مثل Telegram Desktop).
